# Kinetic Grid Hero

An interactive landing page hero section featuring a **kinetic grid background** that dynamically responds to cursor movement. 

## ✨ Overview

**Kinetic Grid Hero** is a frontend design experiment focused on creating an interactive hero section with a responsive grid system.

The background grid reacts to the user's cursor position, producing a subtle distortion and movement effect while the main heading and tagline remain the primary visual focus.

## ✨ Features

- 🌀 **Kinetic Grid Background** — Interactive grid that responds to cursor movement
- 🖱️ **Cursor Interaction** — Grid movement dynamically follows the user's pointer  
- 📱 **Responsive Design** — Adapts across different screen sizes
- ⚡ **Vite-powered** — Fast development and build tooling
- 🎨 **Tailwind CSS** — Utility-first styling
- 💎 **TypeScript** — Type-safe frontend development
